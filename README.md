# Softmax_Red_Wine
Softmax Regression for Wine Quality Classification Dự án này triển khai thuật toán Softmax Regression từ đầu (from scratch) bằng ngôn ngữ Python để phân loại chất lượng rượu vang dựa trên tập dữ liệu UCI Red Wine Quality. Dự án tập trung vào việc hiểu rõ cơ chế toán học của quá trình lan truyền xuôi (forward propagation).
